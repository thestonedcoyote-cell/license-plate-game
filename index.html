Settings & data

Keep control of your game

For this build, photos, sightings, and location data stay on this device unless you explicitly export them.

Theme

Auto follows the phone. Dark mode uses outlined color swatches so black, navy, and dark green don't become indistinguishable little voids.

Location

Use device GPS for sightings, or set a state/province manually. Camera capture never waits on location.

Backup

Export sightings and settings as JSON. Photos are intentionally not exported in this first backup format so a backup doesn't quietly become enormous.

Catalog health

The identification tree exposes what the research catalog knows instead of pretending every record is equally complete.
