# Reference Render Safety

Independent reconstruction solves only part of the image problem. License plates are also government-issued registration credentials, so public reference art must be useful for visual identification without becoming a practical counterfeit template.

This is product policy, not legal advice.

## Rules for public reconstructed plate art

- Use fictitious/sample serials, never a real observed serial.
- Do not reproduce current validation stickers as usable credentials.
- Store/display screen-oriented reference assets, not print-ready manufacturing files.
- Do not publish physical-production dimensions, reflective-material layers, security features, barcodes, hidden marks, or manufacturing data unless clearly necessary for identification and legally cleared.
- Where a highly accurate current rendering could reasonably be mistaken for an issued credential, add a subtle non-obstructive `REFERENCE`/sample treatment in high-resolution source files while keeping phone thumbnails visually useful.
- Never market or describe a reconstruction as an official plate, replacement plate, replica registration, or government-endorsed product.
- Keep legal/specification provenance separate from production-image verification references.

## Why this exists

State vehicle codes commonly prohibit using/displaying fictitious, altered, forged, counterfeit, or unauthorized registration plates. The exact elements and intent requirements vary by state. The License Plate Game use case is a small on-screen identification reference, not manufacturing or displaying a substitute registration plate, but the public asset pipeline should preserve that distinction deliberately.

## Rights review remains separate

A rendering can be safe from credential-counterfeiting concerns and still contain protected creative artwork, logos, seals, trademarks, or sponsor marks. Copyright/trademark/public-use classification and credential-safety classification are separate checks.
