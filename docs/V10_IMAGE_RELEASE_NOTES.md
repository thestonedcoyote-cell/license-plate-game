# v10 image release notes

## Purpose
Publish every plate reference image we can defend as a clean public app asset without treating possession of an official DMV image as redistribution permission.

## Public image rule
The public app may use:

1. original License Plate Game reference renders built from factual/specification/verified visual attributes;
2. artwork with explicit public-domain or redistribution permission documented in the record;
3. separately licensed marks/art only when the license covers this use.

Official production images remain internal verification evidence unless separately cleared. A fair-use argument may be researched, but it is not labeled "clean" merely because the argument exists.

## Reconstruction safety
Public reference renders use fictitious `LPG` serials, screen-size output, no validation stickers/security features, and simplified original motif drawings. They are meant to identify an observed plate, not reproduce an issuable credential.

## Notes requirement
Every image-release batch records purpose, inputs, per-step notes, exceptions, outputs, rights status, and a final recheck. Completion is `COMPLETE`, `COMPLETE_WITH_EXCEPTIONS`, or `INCOMPLETE`.

## Final recheck
Before release, verify that every published asset is either an LPG-created reference render or has an explicit rights basis; every asset maps to a canonical plate UID; no production-only reference asset is accidentally copied into the public tree; and exceptions are noted.
